Konfigurasi dynamic instrumentation tools sebelum Lab 7A

# Install frida dan objection di PC pip install frida-tools pip install objection # Verifikasi instalasi frida --version 16.x.x objection --version 1.x.x # Cek proses di emulator frida-ps -U PID Name ---- ----------- 1234 jakhar.aseem.diva ... (proses lain)

Setup Frida Server di Emulator

# Download frida-server untuk x86 (emulator) # Dari: github.com/frida/frida/releases # File: frida-server-XX.X.X-android-x86 # Push ke emulator adb push frida-server /data/local/tmp/ adb shell chmod 755 /data/local/tmp/frida-server # Jalankan frida-server (root diperlukan) adb shell su -c "/data/local/tmp/frida-server &" # Verifikasi koneksi frida-ps -U | grep diva 1234 jakhar.aseem.diva
Perhatian

Frida Server memerlukan akses root. Gunakan emulator dengan Google APIs (bukan Google Play) atau emulator yang sudah di-root. Emulator API 28 biasanya sudah bisa diroot via adb root.

Lab 7A

Analisis Kriptografi dengan Frida Hooking

Menangkap penggunaan algoritma crypto yang lemah saat runtime di DIVA Android

Script Frida: Hook Crypto API

Simpan sebagai hook_crypto.js:

// hook_crypto.js — Frida script Java.perform(function() { // Hook MessageDigest.getInstance var MD = Java.use('java.security.MessageDigest'); MD.getInstance.overload('java.lang.String') .implementation = function(algo) { console.log("[CRYPTO] MessageDigest: " + algo); return this.getInstance(algo); }; // Hook Cipher.getInstance var Cipher = Java.use('javax.crypto.Cipher'); Cipher.getInstance.overload('java.lang.String') .implementation = function(xform) { console.log("[CRYPTO] Cipher: " + xform); return this.getInstance(xform); }; // Hook SecretKeySpec — tangkap kunci var SKS = Java.use('javax.crypto.spec.SecretKeySpec'); SKS.$init.overload('[B', 'java.lang.String') .implementation = function(key, algo) { console.log("[CRYPTO] SecretKeySpec algo: " + algo); console.log("[CRYPTO] Key bytes: " + Java.use('java.util.Arrays') .toString(key)); return this.$init(key, algo); }; });

Jalankan & Analisis Output

# Jalankan Frida dengan script frida -U -l hook_crypto.js \ jakhar.aseem.diva # Berinteraksi dengan DIVA (Insecure Data Storage) # → masukkan username dan password → Save # Output yang diharapkan (jika ada crypto): [CRYPTO] MessageDigest: MD5 ← RENTAN! [CRYPTO] Cipher: AES/ECB/PKCS5Padding ← RENTAN! [CRYPTO] SecretKey algo: AES [CRYPTO] Key bytes: [77, 121, 83, ...] ← hardcoded!
Berhasil jika

Frida mencetak algoritma kriptografi yang digunakan. Catat semua output: nama algoritma, mode (ECB/CBC/GCM), dan apakah kunci terekspos.

Alternatif: Objection

Jika Frida manual terlalu kompleks, gunakan Objection: objection -g jakhar.aseem.diva explore lalu android hooking watch class javax.crypto.Cipher

Pencarian di Jadx-GUI

1

Lab 7B

Setup Burp Suite sebagai Mobile Proxy

Konfigurasi intercept HTTP/HTTPS traffic dari emulator Android

Konfigurasi Burp Suite

1
Aktifkan Proxy Listener

Burp → Proxy → Options → Edit listener → Bind address: All interfaces, Port: 8080

2
Set Proxy di Emulator

Emulator: Settings → Wi-Fi → Tahan AndroidWifi → Modify → Proxy: Manual → Host: 10.0.2.2, Port: 8080

3
Install Burp CA Certificate

Buka http://burpsuite di browser emulator → Download CA cert → Install ke System Trust Store

4
Verifikasi Intercept

Buka browser emulator → akses website → Burp Proxy tab harus menampilkan request

Install CA Certificate via ADB (API 28+)

# Export Burp CA cert (format DER) # Burp → Proxy → Options → Import/Export CA # Export: Certificate in DER format → burp.der # Convert ke format Android (.0) openssl x509 -inform DER -in burp.der \ -out burp.pem openssl x509 -inform PEM -subject_hash_old \ -in burp.pem | head -1 9a5ba575 cp burp.pem 9a5ba575.0 # Push ke system cert store (butuh root) adb root adb remount adb push 9a5ba575.0 /system/etc/security/cacerts/ adb shell chmod 644 /system/etc/security/cacerts/9a5ba575.0
Alternatif Lebih Mudah

Gunakan Objection untuk bypass SSL pinning jika CA install gagal: objection -g com.target.app explore → android sslpinning disable

Lab 7B

Pengujian IDOR dan Otorisasi dengan Burp Suite

Intercept API request, analisis JWT, dan uji Insecure Direct Object Reference

Skenario Pengujian IDOR

Untuk latihan ini gunakan aplikasi target simulasi atau WebGoat Mobile jika tersedia. Jika tidak, demonstrasikan metodologi dengan DIVA.

## Langkah pengujian IDOR manual: # 1. Login dengan akun uji (user A) # Perhatikan request yang berhasil di Burp # 2. Identifikasi parameter ID di request: GET /api/user/profile?id=1001 HTTP/1.1 Authorization: Bearer eyJhbGci... # 3. Ganti ID ke akun lain di Burp Repeater: GET /api/user/profile?id=1002 HTTP/1.1 # 4. Jika response HTTP 200 + data user lain: HTTP/1.1 200 OK {"id":1002,"name":"Bob","email":"bob@..."} # → IDOR DITEMUKAN! Screenshot bukti.

Analisis JWT Token

## Decode JWT di Burp (atau jwt.io) # JWT terdiri dari 3 bagian: eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9 .eyJ1c2VySWQiOiIxMDAxIiwicm9sZSI6InVzZXIifQ .SflKxwRJSMeKKF2QT4fwpMeJf36POk6yJV_adQssw5c # Decode payload (bagian ke-2, base64url): { "userId": "1001", "role": "user", "exp": 1717200000 } # Uji "alg:none" attack — modifikasi di Burp: # Ubah header ke: {"alg":"none","typ":"JWT"} # Ubah role ke: "admin" # Hapus signature → kirim request # Jika server menerima → KRITIS!
Konteks Lab

Jika tidak ada target aplikasi yang cocok untuk IDOR, dokumentasikan metodologi pengujian secara teoritis dengan contoh request/response simulasi. Poin tetap diberikan untuk pemahaman konsep.

Panduan Laporan

Contoh Format Finding Detail yang Benar

Template untuk setiap temuan dalam laporan pengujian profesional

FINDING DETAIL
F-07 — Penggunaan MD5 untuk Hashing Credentials
ID FindingF-07
SeverityMEDIUM (5.5)
OWASP MobileM10 — Insufficient Cryptography
CWECWE-327
LokasiHardCodeActivity.java (Jadx)
MSTG TestMSTG-CRYPTO-4
Risk ScoreLikelihood 5.0 × Impact 6.0 = 5.5

Deskripsi: Aplikasi menggunakan algoritma MD5 untuk meng-hash credential atau data sensitif. MD5 adalah algoritma hash yang sudah dianggap tidak aman karena rentan terhadap collision attack dan dapat di-crack dengan GPU dalam hitungan detik menggunakan rainbow table.

Bukti (PoC):

// Frida output saat runtime: [CRYPTO] MessageDigest: MD5 // Jadx source: MessageDigest.getInstance("MD5");

Rekomendasi: Ganti MD5 dengan bcrypt (cost factor ≥10) atau Argon2id untuk password hashing. Untuk integrity check non-password, gunakan SHA-256 minimum.
